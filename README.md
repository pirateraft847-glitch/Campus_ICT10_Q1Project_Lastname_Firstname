# Campus ICT10 Q1 Project

Campus Inventory Tools is a two-page website for a campus shop:

- **Receipt Generator** — collect customer details, add multiple items, calculate totals, and print a receipt-style summary.
- **SKU Generator** — combine a product category, product name, and stock quantity into a unique uppercase SKU.

## Pages

- `/` — project overview
- `/receipt` — Skills Test receipt generator
- `/sku` — SKU generator project

The site stores generator history only in the current browser session. It does not require a database or account.

## GitHub Pages

The published files are in `docs/` and are configured to serve from the `main` branch.
